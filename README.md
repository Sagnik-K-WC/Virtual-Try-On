# Virtual Try-On System

A machine-learning-based virtual clothing try-on system that combines
human perception, garment processing, virtual try-on generation, and
real-time camera-based clothing visualization.

## Project Overview

The project aims to develop a unified virtual try-on system supporting
two modes:

1. **Photo-Based Virtual Try-On** — a user provides a person image and
   a garment image, and the system generates a high-quality try-on result.

2. **Real-Time Virtual Try-On** — a camera-based pipeline tracks the
   user's body and garment placement to provide an interactive try-on
   experience.

The system combines pose estimation, human parsing/segmentation,
garment processing, virtual try-on generation, tracking, and rendering.

## Project Status

🚧 **In Development**

The perception and virtual try-on components are currently being
developed and evaluated independently before system integration.
